# 配置管理设计（v3 - 统一配置系统）

本文档说明统一的配置管理系统，解决配置分散、多个配置节点的问题。

---

## 设计目标

### 问题回顾

❌ **v2 存在的问题**：
1. 配置分散：`dynamic_config.yaml` + `vector_models.yaml` + `index_mappings/`
2. 多个管理器：`DynamicConfigManager` + `VectorModelsManager`
3. ES/Redis/上传配置不能动态更新
4. 索引映射配置没有详细说明

### 解决方案

✅ **v3 修正后的配置系统**：
1. **两类配置**：
   - 静态配置（settings.py）：ES/Redis/Celery 连接，需重启
   - 动态配置（dynamic_config.yaml）：业务参数，支持热更新
2. **一个动态管理器**：`ConfigManager`（统一管理动态配置）
3. **明确热更新边界**：业务参数可热更新，基础设施连接不能
4. **索引映射作为模板**：用于创建新索引，使用 ik_max_word 分词

---

## 配置架构

```
config/
├── settings.py              # 静态配置（环境变量）- 需重启
├── config_manager.py        # 动态配置管理器
└── dynamic_config.yaml      # 动态配置 - 支持热更新
```

## 1. 静态配置（settings.py）

**原则**：包含**需要应用重启才能生效**的配置。

```python
# config/settings.py
"""静态配置 - 需要重启才能生效"""
from pydantic_settings import BaseSettings
from functools import lru_cache


class Settings(BaseSettings):
    """
    静态配置（环境变量 + .env 文件）
    
    ⚠️ 修改这些配置需要重启应用
    
    包含：
    1. 应用基础信息
    2. 基础设施连接（ES/Redis/Celery）
    3. 配置文件路径
    4. 安全相关（API Key）
    """
    
    # ========== 应用基础 ==========
    app_name: str = "Document Search API"
    debug: bool = False
    version: str = "3.0.0"
    
    # ========== Elasticsearch（⚠️ 需重启）==========
    es_host: str = "http://localhost:9200"
    es_user: str = ""
    es_password: str = ""
    es_timeout: int = 30
    es_max_retries: int = 3
    es_verify_certs: bool = False
    
    # ========== Redis（⚠️ 需重启）==========
    redis_host: str = "localhost"
    redis_port: int = 6379
    redis_password: str = ""
    redis_db: int = 0
    
    # ========== Celery（⚠️ 需重启 worker）==========
    celery_broker_url: str = ""
    celery_result_backend: str = ""
    
    # ========== 配置文件路径 ==========
    dynamic_config_path: str = "config/dynamic_config.yaml"
    
    # ========== 安全配置 ==========
    api_key: str = ""
    admin_key: str = ""
    require_api_key: bool = False
    
    # ========== 上传目录（⚠️ 需重启）==========
    upload_dir: str = "/app/uploads"
    
    class Config:
        env_file = ".env"
        env_file_encoding = "utf-8"
    
    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        # 自动构建 Celery URL
        if not self.celery_broker_url:
            redis_pwd = f":{self.redis_password}@" if self.redis_password else ""
            self.celery_broker_url = f"redis://{redis_pwd}{self.redis_host}:{self.redis_port}/{self.redis_db}"
        if not self.celery_result_backend:
            self.celery_result_backend = self.celery_broker_url


@lru_cache()
def get_settings() -> Settings:
    """获取静态配置实例（单例）"""
    return Settings()
```

## 3. 统一配置管理器（ConfigManager）

```python
# config/config_manager.py
"""统一配置管理器"""
import yaml
from pathlib import Path
from typing import Any, Dict, List, Optional
import threading
from dataclasses import dataclass

from app.common.logging import get_logger

logger = get_logger(__name__)


@dataclass
class VectorModelConfig:
    """向量模型配置"""
    key: str
    name: str
    dimension: int
    max_length: int
    description: str
    device: str
    load_on_startup: bool


class ConfigManager:
    """
    统一配置管理器
    
    功能：
    - 加载所有动态配置
    - 支持热更新
    - 提供分类访问
    - 线程安全
    """
    
    def __init__(self, config_path: str):
        self.config_path = Path(config_path)
        self._config: Dict[str, Any] = {}
        self._last_modified: Optional[float] = None
        self._lock = threading.RLock()
        
        # 首次加载
        self.reload()
    
    # ==================== 加载和重载 ====================
    
    def reload(self) -> bool:
        """
        重新加载配置文件
        
        返回：是否成功加载
        """
        try:
            with self._lock:
                # 检查文件是否存在
                if not self.config_path.exists():
                    logger.error(f"Config file not found: {self.config_path}")
                    return False
                
                # 检查文件修改时间
                current_mtime = self.config_path.stat().st_mtime
                if self._last_modified and current_mtime == self._last_modified:
                    logger.debug("Config file not modified, skip reload")
                    return True
                
                # 加载 YAML
                with open(self.config_path, 'r', encoding='utf-8') as f:
                    new_config = yaml.safe_load(f)
                
                if not isinstance(new_config, dict):
                    logger.error("Invalid config format: expected dict")
                    return False
                
                # 验证配置结构
                self._validate_config(new_config)
                
                # 更新配置
                self._config = new_config
                self._last_modified = current_mtime
                
                logger.info(f"Config reloaded: {self.config_path}")
                self._log_config_summary()
                return True
                
        except Exception as e:
            logger.error(f"Failed to reload config: {e}", exc_info=True)
            return False
    
    def _validate_config(self, config: dict):
        """验证配置结构"""
        required_sections = [
            "elasticsearch",
            "redis",
            "vector_models",
            "index_mappings",
            "search",
            "upload"
        ]
        
        for section in required_sections:
            if section not in config:
                logger.warning(f"Missing config section: {section}")
    
    def _log_config_summary(self):
        """记录配置摘要"""
        vector_models_count = len(self.get_vector_models())
        index_mappings_count = len(self.get_all_index_mappings())
        
        logger.info(
            f"Config summary: "
            f"{vector_models_count} vector models, "
            f"{index_mappings_count} index mappings"
        )
    
    # ==================== 通用访问 ====================
    
    def get(self, key: str, default: Any = None) -> Any:
        """
        获取配置值（支持嵌套路径）
        
        参数：
            key: 配置键，支持点号分隔，如 "search.default_top_k"
            default: 默认值
        
        示例：
            >>> config.get("search.default_top_k")
            10
            >>> config.get("elasticsearch.host")
            "http://localhost:9200"
        """
        with self._lock:
            # 自动检查并重新加载
            self._auto_reload()
            
            # 解析路径
            keys = key.split(".")
            value = self._config
            
            for k in keys:
                if isinstance(value, dict) and k in value:
                    value = value[k]
                else:
                    return default
            
            return value
    
    def get_section(self, section: str) -> Dict[str, Any]:
        """
        获取配置段
        
        示例：
            >>> config.get_section("elasticsearch")
            {'host': 'http://localhost:9200', 'timeout': 30, ...}
        """
        return self.get(section, {})
    
    def _auto_reload(self):
        """自动检查并重新加载配置（如果文件被修改）"""
        if not self.config_path.exists():
            return
        
        current_mtime = self.config_path.stat().st_mtime
        if self._last_modified is None or current_mtime > self._last_modified:
            logger.info("Config file modified, reloading...")
            self.reload()
    
    # ==================== 向量模型配置 ====================
    
    def get_vector_models(self) -> List[str]:
        """获取所有向量模型键"""
        models = self.get("vector_models.models", {})
        return list(models.keys())
    
    def get_default_vector_model(self) -> str:
        """获取默认向量模型"""
        return self.get("vector_models.default", "bge-large")
    
    def get_vector_model_config(self, model_key: str) -> Optional[VectorModelConfig]:
        """获取向量模型配置"""
        model_data = self.get(f"vector_models.models.{model_key}")
        
        if not model_data:
            return None
        
        return VectorModelConfig(
            key=model_key,
            name=model_data["name"],
            dimension=model_data["dimension"],
            description=model_data["description"]
        )
    
    def is_valid_vector_model(self, model_key: str) -> bool:
        """验证向量模型是否存在"""
        return model_key in self.get_vector_models()
    
    def get_load_on_startup(self) -> bool:
        """获取是否在启动时加载所有模型"""
        return self.get("vector_models.load_on_startup", True)
    
    # ==================== 检索类型配置 ====================
    
    def get_search_types(self) -> List[str]:
        """获取所有支持的检索类型"""
        return self.get("search_types.available", [
            "keyword", "title", "text", "vector", "hybrid"
        ])
    
    def get_search_type_description(self, search_type: str) -> str:
        """获取检索类型的描述"""
        descriptions = self.get("search_types.descriptions", {})
        return descriptions.get(search_type, "")
    
    def is_valid_search_type(self, search_type: str) -> bool:
        """验证检索类型是否有效"""
        return search_type in self.get_search_types()
    
    def get_supported_tags(self) -> List[str]:
        """获取所有支持的知识库标签"""
        return self.get("search_types.tags", [
            "CODE", "SCT", "BUILD", "SYNTAX", "SPEC", "ALG", "DESIGN", "FLOW"
        ])
    
    # ==================== 搜索配置 ====================
    
    def get_search_config(self) -> Dict[str, Any]:
        """获取搜索配置"""
        return self.get_section("search")
    
    # ==================== 上传配置 ====================
    
    def get_upload_config(self) -> Dict[str, Any]:
        """获取上传配置"""
        return self.get_section("upload")
    
    # ==================== 导出 ====================
    
    def dump(self) -> Dict[str, Any]:
        """导出所有配置（用于调试）"""
        with self._lock:
            return self._config.copy()


# ========== 全局实例 ==========

_config_manager: Optional[ConfigManager] = None


def init_config_manager(config_path: str):
    """初始化配置管理器"""
    global _config_manager
    _config_manager = ConfigManager(config_path)
    logger.info(f"Config manager initialized: {config_path}")


def get_config_manager() -> ConfigManager:
    """获取配置管理器实例"""
    if _config_manager is None:
        raise RuntimeError("Config manager not initialized")
    return _config_manager
```

```python
# features/search/repositories/code.py
from app.config.config_manager import get_config_manager

class CodeSearchRepository(BaseSearchRepository):
    async def create_index_if_not_exists(
        self, 
        index_name: str,
        use_vector: bool = False,
        vector_dims: int = 1024
    ):
        """
        创建索引（使用配置的映射模板）
        
        ⚠️ 只在索引不存在时创建
        """
        # 检查索引是否已存在
        if await self.es.indices.exists(index=index_name):
            logger.info(f"Index already exists: {index_name}")
            return
        
        config = get_config_manager()
        
        # ✅ 从配置读取映射模板
        mapping_template = config.get_index_mapping("CODE")
        if not mapping_template:
            raise ValueError("CODE mapping template not found in config")
        
        # ✅ 动态添加向量字段（根据参数）
        if use_vector:
            mapping_template["properties"]["content_vector"] = {
                "type": "dense_vector",
                "dims": vector_dims,
                "index": True,
                "similarity": "cosine"
            }
            logger.info(f"Added vector field to mapping: dims={vector_dims}")
        
        # 获取设置
        settings = config.get_index_settings("CODE")
        
        # 创建索引
        await self.es.indices.create(
            index=index_name,
            body={
```

### 支持热更新的配置

✅ **可以热更新**（修改后调用 API 即可生效）：
- **向量模型配置**：添加/删除模型、修改默认模型
- **索引映射模板**：用于创建新索引（已有索引不受影响）
- **搜索参数**：default_top_k, max_top_k, 过滤配置等
- **上传配置**：max_file_size, chunk_size 等

❌ **不能热更新**（需要重启应用或 worker）：
- **Elasticsearch 连接**：host, user, password, timeout
- **Redis 连接**：host, port, password, db
- **Celery 配置**：broker_url, result_backend（需重启 worker）
- **应用基础信息**：app_name, version, debug
- **上传目录**：upload_dir（需重启）

### 关键设计原则

1. ✅ **配置按性质分类**：

   - 动态配置（dynamic_config.yaml）：可热更新的业务参数

2. ✅ **一个动态配置管理器**：ConfigManager 统一访问

3. ✅ **明确热更新边界**：
   - 业务参数可热更新（搜索、上传、向量模型）
   - 基础设施连接不支持（ES/Redis/Celery）

4. ✅ **索引映射作为模板**：
   - 用于创建新索引
   - 使用 ik_max_word 中文分词
   - 向量字段动态添加

5. ✅ **线程安全**：使用锁保护配置更新
