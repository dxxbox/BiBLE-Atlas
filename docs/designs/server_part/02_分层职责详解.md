# 分层职责详解（v3）

本文档详细说明各层的职责、文件内容、以及代码规范。

---

## 分层架构

```
┌─────────────────────────────────────────┐
│         API Layer (app/api/)            │  HTTP 端点、参数验证
├─────────────────────────────────────────┤
│      Service Layer (features/*/service) │  业务逻辑、编排
├─────────────────────────────────────────┤
│   Repository Layer (features/*/repo)    │  数据访问、查询
├─────────────────────────────────────────┤
│   Infrastructure (infrastructure/)      │  ES, Redis, Vector
└─────────────────────────────────────────┘
```

---

## 1. API 层（Router）

### 职责

✅ **应该做**：
- 定义 HTTP 端点（路径、方法）
- 接收请求参数（path, query, body）
- 验证参数格式（通过 Pydantic）
- 调用 Service 层方法
- 返回 Response 对象
- 处理 HTTP 异常

❌ **不应该做**：
- 业务逻辑计算
- 直接操作数据库
- 复杂的数据处理
- 调用其他 API

### 文件示例

```python
# app/api/v1/search_api.py
"""搜索 API 路由"""
from fastapi import APIRouter, Depends, HTTPException, status

from app.features.search.service import SearchService
from app.features.search.schemas import SearchRequest, SearchResponse
from app.features.search.dependencies import get_search_service
from app.api.deps import validate_api_key
from app.common.logging import get_logger

logger = get_logger(__name__)
router = APIRouter()


@router.post("/search", response_model=SearchResponse)
async def search_documents(
    request: SearchRequest,
    service: SearchService = Depends(get_search_service),
    api_key: str = Depends(validate_api_key)
):
    """
    搜索文档 API
    
    参数：
    - keyword: 搜索关键词
    - doc_type: 文档类型（CODE/SCT/SKILL等）
    - index: 索引名称
    - top_k: 返回结果数量
    
    示例：
    ```
    POST /api/v1/search
    {
      "keyword": "async function",
      "doc_type": "CODE",
      "index": "test_feng",
      "top_k": 10
    }
    ```
    """
    try:
        logger.info(
            f"Search request: keyword='{request.keyword}', "
            f"doc_type={request.doc_type}, index={request.index}"
        )
        
        # ✅ 只调用 Service，不包含业务逻辑
        result = await service.search(request)
        
        logger.info(f"Search completed: {result.total} results found")
        return result
        
    except ValueError as e:
        # 业务错误（如无效参数）
        logger.warning(f"Search validation error: {e}")
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST,
            detail=str(e)
        )
    except Exception as e:
        # 系统错误
        logger.error(f"Search failed: {e}", exc_info=True)
        raise HTTPException(
            status_code=status.HTTP_500_INTERNAL_SERVER_ERROR,
            detail="Search operation failed"
        )
```

### Router 规范

1. **每个文件一个功能域**：`search_api.py` 只包含搜索相关端点
2. **使用 tags 分组**：方便 API 文档分类
3. **统一异常处理**：转换为 HTTPException
4. **记录关键日志**：请求开始、完成、错误
5. **依赖注入**：通过 Depends 获取 Service

## 2. Service 层

### 职责

✅ **应该做**：
- 实现核心业务逻辑
- 编排多个 Repository 调用
- 数据转换和聚合
- 业务规则验证
- 事务管理（如需要）
- 返回业务对象

❌ **不应该做**：
- 直接执行 SQL/ES 查询
- HTTP 相关操作
- 依赖具体数据库实现

### 文件示例

```python
# features/search/search_service.py
"""搜索业务逻辑"""
from typing import List, Optional

from app.features.search.repositories.factory import SearchRepositoryFactory
from app.features.search.schemas import SearchRequest, SearchResponse, SearchResult
from app.infrastructure.vector.vector_tool import VectorTool
from app.infrastructure.vector.rerank_tool import RerankTool
from app.config.config_manager import get_config_manager
from app.common.logging import get_logger
from app.common.exceptions import BusinessException

logger = get_logger(__name__)


class SearchService:
    """
    搜索业务逻辑
    
    职责：
    - 根据文档类型选择 Repository
    - 向量搜索和关键词搜索结合
    - 结果重排序
    - 结果后处理
    """
    
    def __init__(
        self,
        es_client,
        vector_tool: VectorTool,
        rerank_tool: Optional[RerankTool] = None
    ):
        self.es_client = es_client
        self.vector_tool = vector_tool
        self.rerank_tool = rerank_tool
        self.config = get_config_manager()
    
    async def search(self, request: SearchRequest) -> SearchResponse:
        """
        执行搜索
        
        业务流程：
        1. 验证请求参数
        2. 根据 doc_type 获取对应 Repository
        3. 执行搜索（向量 + 关键词）
        4. 重排序（如启用）
        5. 过滤和后处理
        6. 构建响应
        """
        logger.info(f"Searching: {request.doc_type} in {request.index}")
        
        # 1. 验证业务规则
        self._validate_request(request)
        
        # 2. 获取 Repository（工厂模式）
        repository = SearchRepositoryFactory.create(
            doc_type=request.doc_type,
            es_client=self.es_client
        )
        
        # 3. 生成查询向量（如果需要）
        query_vector = None
        if request.use_vector:
            query_vector = await self.vector_tool.generate_vector(
                text=request.keyword,
                model=request.vector_model
            )
        
        # 4. 执行搜索
        search_results = await repository.search(
            index=request.index,
            keyword=request.keyword,
            vector=query_vector,
            size=request.top_k,
            filters=self._build_filters(request)
        )
        
        # 5. 结果处理
        results = self._process_results(search_results, request)
        
        # 6. 重排序（如启用）
        if request.use_rerank and self.rerank_tool:
            results = await self.rerank_tool.rerank(
                query=request.keyword,
                results=results,
                top_k=request.top_k
            )
        
        # 7. 构建响应
        return SearchResponse(
            results=results,
            total=len(results),
            took=search_results.get("took", 0)
        )
    
    def _validate_request(self, request: SearchRequest):
        """验证业务规则"""
        # 检查 top_k 范围
        max_top_k = self.config.get("search.max_top_k", 100)
        if request.top_k > max_top_k:
            raise BusinessException(
                f"top_k cannot exceed {max_top_k}"
            )
        
        # 检查向量模型是否有效
        if request.use_vector:
            valid_models = self.config.get_vector_models()
            if request.vector_model not in valid_models:
                raise BusinessException(
                    f"Invalid vector model: {request.vector_model}"
                )
    
    def _build_filters(self, request: SearchRequest) -> dict:
        """构建过滤条件"""
        filters = {}
        
        # 根据文档类型添加特定过滤
        if request.doc_type == "CODE" and hasattr(request, "language"):
            filters["language"] = request.language
        
        if request.doc_type == "SCT" and hasattr(request, "trace_id"):
            filters["trace_id"] = request.trace_id
        
        return filters
    
    def _process_results(self, raw_results: dict, request: SearchRequest) -> List[SearchResult]:
        """处理搜索结果"""
        hits = raw_results.get("hits", {}).get("hits", [])
        
        results = []
        for hit in hits:
            result = SearchResult(
                id=hit["_id"],
                score=hit["_score"],
                content=hit["_source"].get("content", ""),
                metadata=hit["_source"]
            )
            results.append(result)
        
        return results
```

### Service 规范

1. **一个 Service 一个功能域**：SearchService 只处理搜索
2. **依赖注入到构造函数**：不在方法内创建依赖
3. **清晰的方法命名**：`search()`, `_validate_request()`, `_process_results()`
4. **私有方法前缀 `_`**：区分公共和私有方法
5. **业务异常明确**：使用自定义 BusinessException
6. **记录业务日志**：关键步骤和决策点

## 3. Repository 层

### 职责

✅ **应该做**：
- 封装数据访问逻辑
- 构建查询（ES DSL）
- 执行查询
- 结果映射
- 从配置读取索引映射
- 异常转换（数据库异常 → 业务异常）

❌ **不应该做**：
- 业务逻辑
- 调用其他 Repository
- HTTP 相关操作

### 文件示例

```python
# features/search/repositories/code.py
"""CODE 文档类型的搜索仓储"""
from typing import Dict, List, Optional

from app.features.search.repositories.base import BaseSearchRepository
from app.config.config_manager import get_config_manager
from app.common.logging import get_logger

logger = get_logger(__name__)


class CodeSearchRepository(BaseSearchRepository):
    """
    CODE 文档搜索仓储
    
    职责：
    - 构建 CODE 特定的查询
    - 从配置读取 CODE 索引映射
    - 处理 CODE 特定的过滤条件
    """
    
    def get_doc_type(self) -> str:
        return "CODE"
    
    def build_query(
        self,
        keyword: str,
        vector: Optional[List[float]] = None,
        **filters
    ) -> Dict:
        """
        构建 CODE 查询 DSL
        
        filters 可能包含：
        - language: 编程语言
        - file_path: 文件路径
        """
        must_clauses = []
        
        # 1. 关键词查询
        if keyword:
            must_clauses.append({
                "multi_match": {
                    "query": keyword,
                    "fields": [
                        "content^2",           # 内容权重 2
                        "function_name^3",     # 函数名权重 3
                        "file_path",
                        "comments"
                    ],
                    "type": "best_fields"
                }
            })
        
        # 2. 向量查询
        if vector:
            # 向量查询通过 kNN 单独处理
            pass
        
        # 3. 语言过滤
        if "language" in filters and filters["language"]:
            must_clauses.append({
                "term": {"language": filters["language"]}
            })
        
        # 4. 文件路径过滤
        if "file_path" in filters and filters["file_path"]:
            must_clauses.append({
                "wildcard": {
                    "file_path": f"*{filters['file_path']}*"
                }
            })
        
        return {
            "bool": {
                "must": must_clauses
            }
        }
    
    def get_index_mapping(self) -> Dict:
        """
        ✅ 从配置读取索引映射（不再硬编码）
        """
        config = get_config_manager()
        mapping = config.get_index_mapping("CODE")
        
        if not mapping:
            logger.warning("CODE mapping not found in config, using default")
            # 返回默认映射
            return self._get_default_mapping()
        
        return mapping
    
    def _get_default_mapping(self) -> Dict:
        """默认映射（配置不可用时使用）"""
        return {
            "properties": {
                "content": {"type": "text"},
                "function_name": {"type": "keyword"},
                "file_path": {"type": "text"},
                "language": {"type": "keyword"},
                "line_number": {"type": "integer"},
                "comments": {"type": "text"},
                "vector": {
                    "type": "dense_vector",
                    "dims": 1024,
                    "index": True,
                    "similarity": "cosine"
                }
            }
        }
    
    async def search(
        self,
        index: str,
        keyword: str,
        vector: Optional[List[float]] = None,
        size: int = 10,
        **filters
    ) -> Dict:
        """
        执行搜索（通用逻辑在基类）
        
        这里可以添加 CODE 特定的搜索逻辑
        """
        logger.debug(
            f"[CODE] Searching: keyword='{keyword}', "
            f"filters={filters}, size={size}"
        )
        
        # 调用基类的通用搜索方法
        return await super().search(index, keyword, vector, size, **filters)
```

### Repository 规范

1. **继承基类**：BaseSearchRepository 提供通用逻辑
2. **实现抽象方法**：`get_doc_type()`, `build_query()`, `get_index_mapping()`
3. **从配置读取映射**：不硬编码索引结构
4. **专注数据访问**：不包含业务逻辑
5. **记录数据访问日志**：查询参数、执行时间

## 4. Schemas（数据模型）

### 职责

✅ **应该做**：
- 定义 API 请求/响应模型
- 参数验证（类型、范围、格式）
- 默认值设置
- 文档字符串（生成 API 文档）

❌ **不应该做**：
- 业务逻辑
- 数据库操作

### 文件示例

```python
# features/search/schemas.py
"""搜索功能的数据模型"""
from pydantic import BaseModel, Field, validator
from typing import List, Optional, Dict, Any
from enum import Enum

from app.config.config_manager import get_config_manager


class DocType(str, Enum):
    """文档类型枚举"""
    CODE = "CODE"
    SCT = "SCT"
    SKILL = "SKILL"
    ALG = "ALG"
    DESIGN = "DESIGN"
    FLOW = "FLOW"


class SearchRequest(BaseModel):
    """
    搜索请求模型
    
    自动验证：
    - keyword 不能为空
    - top_k 在合理范围内
    - vector_model 是有效模型
    """
    keyword: str = Field(..., description="搜索关键词", min_length=1)
    doc_type: DocType = Field(..., description="文档类型")
    index: str = Field(..., description="索引名称")
    
    top_k: int = Field(default=10, description="返回结果数量", ge=1, le=100)
    use_vector: bool = Field(default=True, description="是否使用向量搜索")
    vector_model: str = Field(default="bge-large", description="向量模型")
    use_rerank: bool = Field(default=False, description="是否重排序")
    
    # 可选过滤条件（根据 doc_type 不同）
    language: Optional[str] = Field(None, description="编程语言（CODE类型）")
    trace_id: Optional[str] = Field(None, description="跟踪ID（SCT类型）")
    tags: Optional[List[str]] = Field(None, description="标签（SKILL类型）")
    
    @validator('vector_model')
    def validate_vector_model(cls, v):
        """验证向量模型是否有效"""
        config = get_config_manager()
        valid_models = config.get_vector_models()
        
        if v not in valid_models:
            raise ValueError(
                f"Invalid vector model: {v}. "
                f"Valid models: {', '.join(valid_models)}"
            )
        return v
    
    class Config:
        json_schema_extra = {
            "example": {
                "keyword": "async function",
                "doc_type": "CODE",
                "index": "test_feng",
                "top_k": 10,
                "use_vector": True,
                "vector_model": "bge-large",
                "language": "python"
            }
        }


class SearchResult(BaseModel):
    """单个搜索结果"""
    id: str = Field(..., description="文档ID")
    score: float = Field(..., description="相关度分数")
    content: str = Field(..., description="文档内容")
    metadata: Dict[str, Any] = Field(default_factory=dict, description="元数据")


class SearchResponse(BaseModel):
    """搜索响应模型"""
    results: List[SearchResult] = Field(..., description="搜索结果列表")
    total: int = Field(..., description="结果总数")
    took: int = Field(..., description="查询耗时（毫秒）")
    
    class Config:
        json_schema_extra = {
            "example": {
                "results": [
                    {
                        "id": "doc_123",
                        "score": 0.95,
                        "content": "async def search()...",
                        "metadata": {
                            "language": "python",
                            "file_path": "app/search.py"
                        }
                    }
                ],
                "total": 1,
                "took": 23
            }
        }
```

### Schemas 规范

1. **使用 Pydantic**：自动验证和文档生成
2. **明确的 Field 描述**：生成 API 文档
3. **合理的默认值**：提供良好的开箱体验
4. **自定义验证器**：复杂验证逻辑
5. **示例数据**：Config.json_schema_extra

## 5. Dependencies（依赖注入）

### 职责

✅ **应该做**：
- 创建 Service/Repository 实例
- 注入依赖（ES 客户端、工具等）
- 管理生命周期（如需要）

### 文件示例

```python
# features/search/dependencies.py
"""搜索功能的依赖注入"""
from fastapi import Depends

from app.features.search.service import SearchService
from app.features.search.repositories.factory import SearchRepositoryFactory

    es_client = Depends(get_es_client),

    """
    获取 SearchService 实例

    - es_client: Elasticsearch 客户端
    - vector_tool: 向量生成工具

        es_client=es_client,
```

## 6. Infrastructure 层

### 职责

✅ **应该做**：
- 提供基础设施客户端（ES, Redis）
- 封装第三方库
- 提供工具类（向量生成、重排序）
- 连接管理

### 文件示例

```python
# infrastructure/elasticsearch/client.py
"""Elasticsearch 客户端管理"""
from elasticsearch import AsyncElasticsearch
from typing import Optional

from app.config.config_manager import get_config_manager
from app.common.logging import get_logger

logger = get_logger(__name__)

_es_client: Optional[AsyncElasticsearch] = None


async def init_es_client():
    """初始化 ES 客户端（从配置读取）"""
    global _es_client
    
    config = get_config_manager()
    es_config = config.get_section("elasticsearch")
    
    _es_client = AsyncElasticsearch(
        hosts=[es_config.get("host", "http://localhost:9200")],
        timeout=es_config.get("timeout", 30),
        max_retries=es_config.get("max_retries", 3)
    )
    
    # 测试连接
    info = await _es_client.info()
    logger.info(f"ES connected: {info['version']['number']}")


async def close_es_client():
    """关闭 ES 客户端"""
    global _es_client
    if _es_client:
        await _es_client.close()
        logger.info("ES client closed")


def get_es_client() -> AsyncElasticsearch:
    """获取 ES 客户端实例"""
    if _es_client is None:
        raise RuntimeError("ES client not initialized")
    return _es_client
```

## 总结

### 分层职责总结表

| 层 | 文件位置 | 职责 | 不应该做 |
|----|----------|------|----------|
| **API** | `app/api/v1/*.py` | HTTP端点、参数验证、调用Service | 业务逻辑、数据库操作 |
| **Service** | `features/*/{feature}_service.py` | 业务逻辑、编排Repository、数据转换 | 直接数据库操作、HTTP操作 |
| **Repository** | `features/*/repositories/*.py` | 数据访问、查询构建、从配置读取映射 | 业务逻辑、调用其他Repository |
| **Schemas** | `features/*/schemas.py` | 数据模型、验证规则、文档 | 业务逻辑 |
| **Dependencies** | `features/*/dependencies.py` | 依赖注入、实例创建 | 业务逻辑 |
| **Infrastructure** | `infrastructure/*/` | 基础设施客户端、工具类 | 业务逻辑 |

### 关键设计原则

1. **单一职责**：每个类/文件只做一件事
2. **依赖注入**：通过构造函数或 FastAPI Depends
3. **从配置读取**：索引映射、向量模型等不硬编码
4. **异常分层**：数据层异常 → 业务异常 → HTTP异常
5. **日志分层**：数据访问日志、业务日志、API日志
